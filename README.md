# Personal Knowledge

一个独立、公开、持续维护的个人知识库。

用于沉淀技术学习、游戏开发、创作研究与日常探索中的有价值结论。内容可以来自个人实践、阅读和 AI 辅助讨论，但不把聊天记录原文直接当作知识成果。

## 内容索引

- [编程技术](programming/README.md)：C++、网络编程、算法与工程实践
- [游戏开发](game-development/README.md)：设计思路、玩法机制、原型与实验记录
- [创作研究](creative-writing/README.md)：写作技巧、叙事与世界观研究
- [学习笔记](learning/README.md)：数学、语言、绘画及跨领域学习
- [想法与探索](ideas/README.md)：尚在形成中的灵感与假设
- [生活研究](life/README.md)：适合公开分享的经验与资料

## 原则

1. **内容优先**：默认使用标准 Markdown；必要时独立提供 HTML/JS 交互示例。
2. **公开优先审查**：本仓库是 Public。任何提交都可能被公开访问及保存，禁止归档秘密、身份凭证、内部资料或未经许可的私人信息。
3. **准确而非堆积**：区分事实、推测、个人判断与尚待解决的问题；尽可能标明来源及验证状态。
4. **逐步完善**：先记录可复用的知识，再补充示例、引用与关联。
5. **框架无关**：知识内容不依赖特定博客框架或个人网站。

## 如何归档

在 AI 对话中提出“归档到 personal-knowledge”，说明主题和希望记录的内容。写入前应检查现有文章，优先合并更新；尤其在公开仓库中，必须先检查隐私和版权风险。

格式与操作规范参见 [AGENTS.md](AGENTS.md)，新文章可参考 [文章模板](templates/article.md)。
