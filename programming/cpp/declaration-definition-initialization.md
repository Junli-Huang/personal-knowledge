# C++ 变量的声明、定义与初始化：从 int a 到 VS C4700

最初的问题很简单：`int a;` 在 C++ 中叫什么？接着，在 Visual Studio 中看到“使用了未初始化的局部变量”的 C4700 错误，又会发现**定义、初始化、赋值和使用**并不是一回事。

本文以 C++11/14 为主。

## 1. int a 是声明，还是定义？

```cpp
int a;           // 声明，也是定义
int b = 10;      // 声明、定义，并初始化
extern int d;    // 通常仅声明，不定义（命名空间作用域）
```

**声明（Declaration）**告诉编译器一个名字及其类型等信息；**定义（Definition）**是满足程序对实体定义要求的声明。对这里的非 `extern` 变量，定义也意味着创建相应变量对象。可以多处重复声明同一个外部变量，但普通变量的定义要满足单一定义规则（ODR）。

“定义也是声明，但声明不一定是定义”是理解后续 `extern` 的关键。

## 2. 初始化不等于赋值

```cpp
int a = 10; // 创建 a 时初始化
a = 20;     // a 已经存在，对它赋值
```

`int a = 10;` 尽管写了等号，术语仍是**拷贝初始化（Copy Initialization）**，不是对已存在对象进行赋值（Assignment）。

C++11/14 常见形式：

```cpp
int a = 10;  // 拷贝初始化
int b(10);   // 直接初始化
int c{10};   // 直接列表初始化
int d = {10}; // 拷贝列表初始化
int e{};     // 值初始化，结果为 0
```

花括号列表初始化还可以阻止某些窄化转换，例如把非整数浮点常量放进 `int`。

## 3. 为什么 Visual Studio 报 C4700？

```cpp
#include <cstdio>

int main()
{
    int c;               // 只是定义，未显式初始化
    std::printf("%d", c); // 读取未初始化的局部变量
}
```

对通常的自动存储期局部 `int` 来说，`int c;` 的默认初始化不会为其设置确定的整数值；**问题出在后续读取，而不在这一行声明本身**。

MSVC 中相关诊断：

| 诊断 | 常见含义 |
| --- | --- |
| C4700 | 使用了未初始化的局部变量（错误） |
| C4701 | 可能使用未初始化的局部变量（警告） |

不同编译选项、代码路径和静态分析能力会影响能否诊断。即使编译器没有报错，也不能依赖未初始化值。

最直接的写法：

```cpp
int c{};    // 0，适合希望有确定初值的场合
int d = 0;  // 也为 0
```

**并不是所有变量都必须立即填入一个无意义的 0**：如果逻辑保证在第一次读取前必然赋值，也可以先声明，随后在合适的地方赋值；只是这种路径必须明确。

## 4. 为什么全局 int a 常常是 0？

```cpp
int globalValue; // 静态存储期：零初始化

int main()
{
    int localValue; // 自动存储期：未显式初始化
    int safeValue{}; // 0
}
```

全局变量具有静态存储期，在没有显式初始化器时会被零初始化。而普通局部 `int` 不会因为也写成 `int a;` 就自动得到 0。

静态存储期还适用于函数内部的 `static` 局部变量，但它的作用域仍可能只在函数体内。

## 5. extern 是另一个问题

```cpp
extern int d;     // 声明；期待别处提供定义
int d = 100;      // 定义，并初始化
extern int e = 1; // 在命名空间作用域，这是定义，因为有初始化器
```

只写声明，并不产生另一份变量。不同 `.cpp` 如何通过 `extern` 使用同一数据、为何找不到定义会触发链接错误，见 [extern、翻译单元与链接属性](extern-translation-unit-linkage.md)。

## 6. 几个概念快速对照

| 术语 | 英文 | 关注的问题 |
| --- | --- | --- |
| 声明 | Declaration | 编译器认识这个名字吗？ |
| 定义 | Definition | 实体的定义在哪里？ |
| 初始化 | Initialization | 创建对象时初始状态是什么？ |
| 赋值 | Assignment | 对已存在的对象写入新值 |
| 存储期 | Storage Duration | 对象存活多久？ |
| 链接属性 | Linkage | 不同作用域/翻译单元里的名字是否指向同一实体？ |

**一句话**：`int a;` 是声明兼定义，但对于普通局部 `int`，它不保证有可读取的初始值。声明、定义、初始化、赋值要分开理解。
